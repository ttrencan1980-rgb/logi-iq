# Logi IQ – mobilná appka skladu

Obrazovky appky Logi IQ (vychystávanie, príjem, inventúra, hľadanie tovaru, robot-dispečer).

- Appka: https://ttrencan1980-rgb.github.io/logi-iq/
- Ukážka s vymyslenými dátami: https://ttrencan1980-rgb.github.io/logi-iq/?ukazka

Tento repozitár obsahuje len obrazovky. Kľúč v `config.js` je verejný kľúč Supabase (anon), ktorý je určený
na použitie v prehliadači. Dáta chráni databáza: prístup len pre prihlásených používateľov podľa roly,
registrácia je vypnutá a účty zakladá správca. Databáza, serverové funkcie a testy sú v súkromnom repozitári.
